# Multi-Class-DNA-Sequence-Classification
Multi-class DNA sequence classifier (human, chimp, dog) using a custom CNN + Bi-LSTM + Attention + MoE model. Includes EDA, k-mer feature engineering, training with label smoothing &amp; SWA, evaluation (ROC-AUC, CV), ablation study, LIME explainability, and cross-species generalization testing. Built with TensorFlow, scikit-learn, pandas.
